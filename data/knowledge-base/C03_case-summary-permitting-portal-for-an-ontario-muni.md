# Case Summary: Permitting Portal for an Ontario Municipality

Document ID: C03
Type: Case summary
Owner: Public Sector, Canada
Last updated: 2025-11-20
Status: Current

- Problem: paper-based building permits with 12-week turnaround.
- Solution: online permit portal, bilingual (English and French), meeting AODA and WCAG 2.1 AA.
- Result: 70% of applications submitted online in year one; turnaround down to 6 weeks.
- Lesson: accessibility testing with real assistive-technology users found issues that automated tools missed.
