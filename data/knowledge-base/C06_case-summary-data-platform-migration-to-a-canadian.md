# Case Summary: Data Platform Migration to a Canadian Cloud Region

Document ID: C06
Type: Case summary
Owner: Banking & Financial Services, Canada
Last updated: 2026-05-19
Status: Current

- Problem: analytics platform hosted outside Canada conflicted with the client's new residency rules.
- Solution: migrated to a cloud region in Canada with masked data in non-production.
- Result: completed in 7 months with no residency findings in the client's audit.
- Lesson: confirm residency terms in the SOW before architecture work begins.
