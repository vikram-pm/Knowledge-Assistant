# Estimation Guidelines

Document ID: B05
Type: Playbook
Owner: Delivery Excellence
Last updated: 2024-03-12
Status: Current

- Estimate with three points (optimistic, likely, pessimistic) for every work package.
- Add 15% contingency for fixed-price work and 10% for time-and-materials work.
- Have a second architect review any estimate above 2,000 person-hours.
