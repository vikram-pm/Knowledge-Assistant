# Case Summary: Claims Automation for a Canadian Insurer

Document ID: C02
Type: Case summary
Owner: Insurance, Canada
Last updated: 2026-03-11
Status: Current

- Problem: simple auto claims took 9 days on average.
- Solution: rules-based triage plus document extraction with human review for low-confidence cases.
- Result: straight-through processing for 35% of simple claims; average cycle time down to 4 days.
- Lesson: set confidence thresholds with the claims team, not just the data science team.
