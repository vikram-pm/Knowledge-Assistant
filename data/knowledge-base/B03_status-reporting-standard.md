# Status Reporting Standard

Document ID: B03
Type: Playbook
Owner: Delivery Excellence, Canada
Last updated: 2026-01-15
Status: Current

- Send a weekly status report every Friday using template T04.
- Use RAG status for scope, schedule, budget and quality.
- Amber: at risk but recoverable within the current phase. Red: needs client or leadership decision.
- Any Red status is escalated to the account delivery lead on the same day.
