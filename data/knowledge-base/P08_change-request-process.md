# Change Request Process

Document ID: P08
Type: Process
Owner: Delivery Excellence, Canada
Last updated: 2025-11-18
Status: Current

## When a change request is needed
Any change to scope, timeline, cost or key personnel after the SOW is signed.

## Steps
1. Delivery manager drafts the change request with impact on scope, schedule, cost and risk.
2. Internal review: changes under $50,000 CAD are approved by the account delivery lead. Changes of $50,000 CAD or more also need the regional delivery head.
3. Client signs the change request before work begins.
4. Update the project plan, RAID log and billing schedule within 2 business days.
