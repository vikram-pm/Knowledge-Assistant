# Staffing Request Process

Document ID: P04
Type: Process
Owner: Resource Management Group, Canada
Last updated: 2026-03-02
Status: Current

## When to raise a request
Raise a staffing request as soon as a role is confirmed in an SOW or change request.

## Steps
1. Delivery manager submits the request in the resourcing tool with role, skills, start date, location and billing rate.
2. Resource Management Group proposes bench candidates within 5 business days.
3. If no bench match exists, the request goes to internal mobility and then external hiring.
4. Client interviews, if required, are scheduled by the delivery manager.

## Lead times
Standard roles: 2–3 weeks. Niche skills (for example, mainframe or Québec French-language roles): 4–6 weeks.
