# Security Incident Reporting

Document ID: P10
Type: Policy
Owner: Information Security, Canada
Last updated: 2026-02-14
Status: Current

- Report any suspected security incident to the Security Operations Centre immediately through the incident hotline or the security portal.
- Do not try to investigate or contain the incident yourself unless instructed.
- The delivery manager notifies the client according to the SOW's incident terms, after confirming with Information Security.
- Incidents involving personal information are assessed for breach reporting under PIPEDA.
