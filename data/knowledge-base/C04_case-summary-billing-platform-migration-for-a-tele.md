# Case Summary: Billing Platform Migration for a Telecom Provider

Document ID: C04
Type: Case summary
Owner: Communications, Canada
Last updated: 2023-08-14
Status: Current

- Problem: legacy billing system end-of-life.
- Approach: phased cutover by customer segment over 4 waves, with 2 weeks of parallel billing runs before each wave.
- Result: migration finished with under 0.1% billing disputes.
- Lesson: parallel runs caught 14 rating defects before customers saw them.
