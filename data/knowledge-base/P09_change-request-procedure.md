# Change Request Procedure

Document ID: P09
Type: Process
Owner: Delivery Excellence
Last updated: 2022-05-09
Status: Archived

## Standard changes
Changes under $25,000 CAD are approved by the delivery manager. Larger changes need the account delivery lead.

## Emergency changes
For urgent production fixes, the delivery manager may start work on verbal client approval. A written change request must be signed by the client within 5 business days.
