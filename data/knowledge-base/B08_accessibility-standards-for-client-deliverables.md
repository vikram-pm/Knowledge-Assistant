# Accessibility Standards for Client Deliverables

Document ID: B08
Type: Playbook
Owner: Experience Design, Canada
Last updated: 2026-05-08
Status: Current

- Digital products built for Ontario clients must meet AODA requirements, which reference WCAG 2.0 AA. Our standard is WCAG 2.1 AA for all Canadian clients.
- Run automated and manual accessibility testing before user acceptance testing.
- Accessibility defects of high severity block go-live.
